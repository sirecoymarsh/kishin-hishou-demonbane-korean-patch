# 기신비상 데몬베인(機神飛翔デモンベイン) PC판 한국어 패치 작업물

니트로플러스의 『기신비상 데몬베인』(2006) 일본판 PC판에 한국어 대사·UI와 여러 편의 기능을 넣는 패치의 코드·도구·번역 텍스트를 보관하는 저장소입니다.
원본 게임 파일, 추출한 원문 데이터, 음성·영상, 실행 파일과 빌드 결과는 넣지 않았습니다. 한국어화한 그림은 `assets-ko/` 에 있습니다(고해상도 CG 제외). 패치를 다시 만들려면 원본 게임이 따로 필요합니다.
배포 꾸러미는 릴리스 `patch-20261119` 에 있습니다.

## 추가·변경 사항

원판(원래 게임) 대비 이 패치가 더하고 바꾼 것을 정리했습니다. 괄호 안은 근거(파일 이름, 릴리스 태그, 진행 기록 날짜)입니다. 확실하지 않은 것은 「(추정)」으로 표시했습니다. 11-18 판 안내문 `release-1118/template/변경사항.md` 는 10월 30일 판 이후 바뀐 것만 적고 있어, 그 앞 내용은 합본·검수 기록에서 모았습니다.

### 번역 범위

- **번역 원문**: 일본어 원문 기준입니다.
- **본문 대사·선택지**: 대본 전체(`script.pak`, 대본 119개). 처음 한국어판(10월 이전, GPT 번역으로 추정) 위에, 11-01 에 Gemini 4 Argon 초벌 재번역 104묶음 + 제미나이 3.8 Flash 로 남은 33묶음을 넣고 Claude 가 원문 대조로 다시 검수했습니다(미번역 0, `proxy-dll/merge/합본.md`, `script-translation/work/agents/BRIEF.md`). 이어 직역투를 다듬는 교정을 했습니다(`script-translation/gemini_polish/지침.md`).
- **메뉴·UI**: 메뉴 대본(타이틀·감상실·CG 감상 등), 환경설정 창에서 일본어로 남아 있던 곳, 확인 창(「타이틀 화면으로 돌아갈까요?」「게임을 끝낼까요?」「영상을 건너뛸까요?」 등), 로고 화면, 커맨드 리스트 등 메뉴 그림 11장(`dmpack004_ko_menu.dat`).
- **영상**: 한국어 영상 4편(`0mpeg.pak` 덧씌우기). 오프닝 두 편과 투소드 전투 영상 두 편으로 보입니다(`proxy-dll/release/배포_구성_초안.md`; 릴리스 노트는 「한국어 오프닝 4편」이라고 적음 — 어느 쪽이 맞는지 확인 필요).
- **패배 화면 음성 자막**: 패배할 때 음성만 나오던 대사에 자막(`story_subs.tsv`, 10-18).
- **서재(LORE) 책**: 마술사·마도서 사전, 데우스 마키나 사전(본 패치), 소설 6권(따로 받는 꾸러미). 11-20~21 에 사전 권수를 늘리고 목차·그림·영상을 더한 판은 아직 배포 꾸러미에 들어가지 않았습니다(아래 「알려진 문제」).
- **DUEL 정보 창 자료**: 마술사·마도서·기체 자료·기술표·기술 유래·기술명 대사·커맨드 리스트(한국어로 새로 작성).

### 편의 기능 (원판에 없던 것)

- **자동 전투**: 이야기·프리 파이트·DUEL 전투를 AI 가 대신 싸웁니다(`autobattle\autobattle.ini` 의 `agent`, 환경설정 전투 탭의 「자동 전투」 체크). 자동 전투 중 ESC 를 누르면 그 전투를 직접 조작할지 묻습니다.
- **DUEL 주인공 기체 AI**: 원래 CPU AI 가 없던 주인공 5기체(데몬베인·데몬베인 공중전·아이온·앰브로시우스·D 투소드)에 AI 를 새로 붙였습니다(11-01, `proxy-dll/검수결과.md`). 균형 모드의 상대별 AI 다수 손질(로드 비야키·앰브로시우스·네로·크라켄·벨제부트 등).
- **DUEL 난이도·하드 모드**: 균형 모드에서 이지·노말·하드 AI(11-02). 하드에서는 적 에너지가 빨리 차고 필살기가 강해짐(`hard_v11.h`, 11-02 조사·구현). 게임에 숨어 있던 셋째 난이도 「어려움」을 이야기에서도 고를 수 있게 했습니다(노말과 같은 수치 + 기술 더함).
- **이야기·프리 파이트 「어려움」 보강(11-19, v31)**: 티베리우스 폭식 대죄·오거 비검·비룡·데몬 블러드 금기의 피 해방 동안 적이 받는 피해 절반(끊기지 않음), 원령 주탄 모으는 시간 절반. 쉬움·보통은 그대로(끄기: `story_onryou_fast=0`).
- **서재(LORE)**: 감상실에서 EPUB 책을 읽는 서재. 「책 들여오기」로 EPUB 을 더하면 표지·제목과 함께 목록에 나타납니다(`ko-library\books`, 11-19).
- **DUEL 정보 창**: DUEL 선택 화면에서 마술사·기체 칸을 누르면 자료를 봄. 기술명 대사는 누르면 음성 재생. 본편을 끝낸 세이브에서 잠긴 칸이 열림.
- **FINISHERS 목록**, **프리 파이트 컨티뉴**, 레무리아 엔딩 뒤 **「다시 마지막 전투로」**.
- **대화 기록 점프**: 대화 기록에서 그 대사 자리로 이동(`version.dll` 후크, 게임 폴더의 「대화 기록 점프 안내.txt」).
- **전투 카메라**: 전투 중 시점 돌리기·당기기(`d3dxof.dll` 후크, 「전투 카메라 안내.txt」, 아래 단축키 표).
- **스토리 차트**: 감상실에서 이야기 갈래를 보는 화면(`dh_ex_story.nps`, 10월).
- **모든 콘텐츠 열기(11-18, v30)**: 환경설정 기본 탭 맨 아래 체크 칸. 켜면 감상실의 CG·DUEL 기체·스토리 차트·극장·피니셔와 DUEL 정보 창의 잠긴 칸이 모두 열립니다. 세이브와 진행 기록은 바꾸지 않아 끄면 원래대로 잠깁니다.
- **전투 전 자동 저장**: 「저장할까요?」에 예 → 다음 빈 칸에 바로 저장.
- **창이 뒤에 있어도**: 소리가 나고 자동 전투가 계속 싸움. 대신 그동안 다른 창에서 친 키가 전투에 들어가지 않게 입력을 막음(`isolate_input`).
- **인물별 음성 크기**: 환경설정 사운드 탭에서 인물마다 음성 크기 조절(`[voice_volume]`).
- **설정 창 꾸밈**: 환경설정 창을 마도서 모양 그림으로(`settings_skin`), 전투 탭에 난이도 설명.
- **컨티뉴**: 패배하면 GAME OVER 와 적 대사 뒤에 컨티뉴 창(원작 YES/NO 그림), 컨티뉴 대기 시간을 음성 길이에 맞춤.

### 화면·그래픽 개선

- **4K·화면 크기(11-18)**: 환경설정 → 기본 탭 「화면 크기」(원래 크기 / 2배 창 / 3배 창 / 모니터 전체), 누르는 즉시 바뀝니다. 대사와 전투는 그 해상도로 다시 그립니다(`hires-dll/`, `khd4k.dll`).
- **고화질 꾸러미(따로)**: CG·배경·메뉴 그림 4배(약 2.6GB)와 데몬베인 로봇 텍스처 126장 4배(`dmpack600_retex.dat`). 없어도 게임은 돌고, 그림만 원래 그림을 부드럽게 키운 모습으로 보입니다.
- **한글 글꼴 「KHD Korean」**: Noto Sans CJK 바탕의 CP932 매핑용 수정 글꼴(SIL OFL 1.1), `FONTCHANGER.dll` 로 교체.
- **대사 줄 바꿈과 대사 창 4줄**(11-18).
- **한국어 오프닝 다시 만듦**: 찢김·늦게 도착하는 그림을 없앰(11-18).
- **dgVoodoo 제거(11-18)**: 예전 판은 dgVoodoo(D3D8→D3D11)를 써서 전투가 열리는 데 20초 넘게 걸렸는데, 이제 몇 초로 줄었습니다.
- **화면 보호기 막기**: 게임 중에는 화면이 꺼지지 않게 함(전투 중 화면 보호기가 게임을 끄던 것).

### 버그 수정

- 한글이 든 설치 경로에서 첫 전투 직전·시스템 정보에서 게임이 꺼지던 것(11-18).
- 게임 창이 뒤에 있을 때 다른 창에서 친 키가 전투에 들어가 일시정지·종료되던 것.
- 확인 창이 영어·일본어로 나오던 것.
- DUEL 정보 창에서 대사를 재생할 때 빈 대화창이 잠깐 뜨던 것.
- 2P 크라켄·벨제부트·리베르 레기스·오거·네로의 잡기에서 붙잡힌 기체가 손에 붙지 않던 것.
- 웨이틀리 요그 소토스 주문 음성이 앞 음성에 막혀 안 나오던 것.
- 신수 형태를 원작 필살기 조건(체력 400 이하)으로.
- 앰브로시우스·투소드 전용 DUEL 장면에 효과음 목록이 빠져 있던 것(11-01 검수).
- 커맨드 리스트가 일본어로 나오던 것(덧씌우기 묶음 항목 이름의 `/`·`\` 차이, 11-18 밤).
- 전투 카메라 마지막 시점이 엉뚱한 값으로 저장돼 나가던 것(11-19).

### 설치·제거 방식

- **대상 판본**: 일본판 「機神飛翔デモンベイン」 설치본 + 공식 1.20 업데이트, Windows 10·11.
- **차분판(릴리스 `patch-20261119`)**: `KishinHisho_KO_20261119_xdelta.zip` 을 게임 폴더에 풀고 「한국어패치_설치.bat」 실행 → 원본 다섯 파일(`system.dll`·`demonbane.dll`·`script.pak`·`0cg.pak`·`0advdata.pak`)을 xdelta 로 고치고, 새 데이터 묶음은 원본 묶음(`dmpack.dat`·`mpeg.pak`·`cg.pak` 등)에서 만들어 냅니다. 되돌리기는 「한국어패치_제거.bat」. 소설 6권은 `KishinHisho_KO_20261118_Novels.zip` 을 따로 풉니다. SHA-256 파일이 함께 있습니다.
- **덮어쓰기판(11-19, `release-1118/template_zip/`)**: ZIP 을 게임 폴더에 그대로 풀어 덮어씁니다. 덮어쓰는 원래 파일은 위 다섯 개뿐이고 나머지는 새로 더해지는 파일입니다. 백업은 사용자가 직접 합니다. 받은 ZIP 은 「차단 해제」를 권합니다(서명 경고).
- **설치기판(11-18, `release-1118/template/`, 지금은 쓰지 않음)**: `Install.cmd` 가 원본 해시를 확인하고(달라도 경고만) 게임 폴더 옆에 백업 폴더를 만들며, `Restore.cmd` 로 되돌리고 `Check.cmd` 로 미리 검사.
- **원본 큰 파일은 고치지 않음**: `dmpack.dat`·`dmpack001.dat`·`mpeg.pak` 은 그대로 두고, 바뀐 메뉴 그림 11장과 한국어 영상 4편만 덧씌우기 묶음으로 넣습니다.
- **실행**: 게임 폴더의 `Play.cmd`(Locale Emulator 로 일본어 코드 페이지 실행, 한국어 Windows 에서 그대로). 대리 DLL 은 `dinput8.dll`(자동 전투 등)·`version.dll`(대화 기록 점프)·`d3dxof.dll`(전투 카메라)입니다.
- **이전 판에서 옮겨 올 때**: 10월 29일·30일 한국어 패치 위에 덮어쓸 수 있고 세이브는 그대로입니다. `d3d8.dll`·`dgVoodoo.conf` 는 지워야 합니다. 다시 풀면 `autobattle.ini` 설정이 기본값으로 돌아갑니다.
