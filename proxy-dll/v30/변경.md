# 대리 DLL v30 (11-18 밤) — 환경설정 「모든 콘텐츠 열기」

v29c(061b0a62) + 아래. 빌드 `build.cmd`(`cmd /d /c <전체 경로>`) → `out\dinput8.dll` **sha256 331cec40**. 새 파일 `src\unlock_all.h`.

## 사용자 말
「근데 옵션에 모든 콘텐츠 개방을 내가 안넣었었나?」 → (없다고 답함) → 「그렇네 옵션에 넣어줘. 그리고 패치만 다시 만들면 되겠지」.

## 바뀐 것
- 환경설정 기본 탭 「기본 설정」 묶음 맨 아래(원래 숨은 칸 0x43F 자리)에 체크 칸 「모든 콘텐츠 열기 (감상실·DUEL·차트)」(id 0x5A20). 켤 때 확인 창(스포일러 경고·「세이브와 진행 기록은 바꾸지 않으므로 끄면 원래대로 다시 잠깁니다」, 기본 단추 아니요). 끌 때는 바로. autobattle.ini `[autobattle] unlock_all=0|1`.
- 방식 = vn-qol qa-mode (가) 읽기 가로채기, 게임 기록은 한 바이트도 안 씀:
  - system.dll 0x10021450(대본 조건 계산기, stdcall(engine, 조건 문자열 객체(char* +4), a3, a4)) 머리 7바이트를 우리 함수로. 켜져 있고 a3=a4=0(A·CHOICE 조건)이고 메뉴 화면(시스템 메뉴 값 [system.dll+0xEE680]+0x18E2C 의 아래 16비트 0x7E2 — 타이틀·감상실·DUEL·정보 창·스토리 차트·극장)일 때, 콘텐츠 깃발 조건(StageNN·クリア·真クリア·RPp>n·RPu_*·RP_da*·RP_end*·RPcN·RPeN·RPmN, =1/=true/>n)만 참. 이야기 대본(메뉴 값 0x0/0x2)의 クリア(2회차 건너뛰기 등)는 진짜 값. 메뉴 대본이 쓰는 RPu_*·RPc*·RPp·RPm* 은 들어올 때마다 다시 계산하는 지역 변수라 남지 않음.
  - CG 감상: 목록 만드는 함수(0x1003b6de·0x1003b6ea)와 세는 함수(0x1003dfa8·0x1003dfb0)의 「엔진 디버그면 전부 엶」 갈래 판정 je 넷을 켜 있는 동안 NOP, 끄면 원래 바이트.
  - 시험 스위치 `unlock_trace=1`(조건 처음 80개를 로그에).
- 처음엔 메뉴 값을 계산기 첫 인자(+0x18E2C)에서 읽어 틀렸다(0x100d06c8 = 빈 문자열) — 그 인자는 게임 객체가 아님. MenuMask 와 같은 전역 객체로 고침.
