## 방법(잰 것)
- dmpack.dat(334 MB)·dmpack001.dat(32 MB)는 6천여 항목 중 **메뉴 그림 11장만** 바뀜(나머지는 내용 같고 자리만 밀림) →
  그 11장만 담은 덧씌우기 dmpack 으로(약 5 MB). 통째 xdelta 는 블록이 거의 다 달라 줄지 않음.
- mpeg.pak 은 12편 중 4편만 바뀜 → 그 4편만 담은 `0mpeg.pak` 덧씌우기(원본 mpeg.pak 은 사용자 것 그대로).
  다른 한국어 패치(`P:\AI\Codex\projects\khd-external-ko-20261030`)가 이미 0mpeg.pak 을 씀 = 엔진이 받음. **우리 판으로는 시험 전.**
- script.pak 은 바꿔 넣기 그대로(0script.pak 으로 바꾸면 0replay.pak 과 덮는 순서가 달라질 수 있음).
- `autobattle\autobattle.ini` 는 사용자 설정이 든 파일 → 배포엔 기본값 판을 따로.

## 정할 것
1. 한국어 영상 4편(압축 230 MB)을 게임 패치에 넣을지, 따로(선택) 둘지 — 따로 두면 게임 패치는 약 220 MB.
2. 바탕 = 일본판 + 공식 1.20 업데이트로 할지(1.20 파일은 안 실음).
3. 4K 모듈은 게임 패치 쪽(고화질 애셋 없이도 돎) — 고화질 꾸러미로 옮길 수도 있음.
4. 고화질을 늘릴지(다른 기체 텍스처·CG·배경 4배·오프닝 업스케일). 32비트 게임이라 데몬베인 텍스처만으로 주소 공간
   2 GB 중 915 MB(10-16 측정) — 늘리면 메모리 한계부터 확인.
