기신비상 데몬베인 한국어 패치 (2026-11-18)

■ 필요한 것
- 일본판 「機神飛翔デモンベイン」 설치본과 공식 1.20 업데이트
- Windows 10 또는 11

■ 설치 — 게임 폴더에 압축을 풀어 덮어쓰기
1. 받은 zip 파일을 오른쪽 클릭 → 속성 → 아래쪽 「차단 해제」에 체크 → 확인.
   이것을 하지 않으면 Windows 가 「인터넷에서 받은 서명 없는 파일」이라며 게임을 켤 때마다 경고합니다.
2. 게임 폴더를 통째로 백업해 두기를 권합니다.
   이 패치가 덮어쓰는 원래 파일은 system.dll · demonbane.dll · script.pak · 0cg.pak · 0advdata.pak 다섯 개이고,
   나머지는 새로 더해지는 파일입니다.
3. zip 안의 내용을 게임 폴더(script.pak 이 있는 폴더)에 그대로 풀고, 같은 이름의 파일은 모두 덮어씁니다.
   Windows 의 「압축 풀기」는 새 폴더를 만들어 풀려고 하니, 대상 폴더를 게임 폴더로 바꾸거나
   풀린 내용 전체를 게임 폴더에 복사해 넣으세요.
4. 게임은 게임 폴더의 Play.cmd 로 켭니다.

- 게임 폴더 경로에 한글이 있어도 됩니다.
- 처음 켜면 PRESS START 뒤에 환경설정(키 설정) 창이 한 번 뜹니다.

■ 10월 29일·30일 한국어 패치를 쓰던 경우
- 위와 같이 덮어쓰면 됩니다. 세이브는 그대로입니다.
- 게임 폴더의 d3d8.dll 과 dgVoodoo.conf 는 지워 주세요. 이번 판부터 쓰지 않으며,
  남아 있으면 전투가 열리는 데 20초 넘게 걸립니다.

■ 다시 풀 때(새 판으로 바꿀 때)
- autobattle\autobattle.ini 도 새 판으로 덮어써지므로 화면 크기·자동 전투·DUEL 설정 등이 기본값으로 돌아갑니다.
  환경설정에서 다시 고르면 됩니다. 세이브와 서재의 읽던 위치는 그대로입니다.

■ 되돌리기
- 2번에서 백업해 둔 게임 폴더(또는 원래 파일 다섯 개)로 되돌리면 됩니다.

■ 따로 받는 꾸러미 — 같은 방법으로 게임 폴더에 풀기, 푸는 순서는 상관없음
- KishinHisho_KO_20261118_Novels : 서재(LORE)에 데몬베인 소설 6권. 풀면 다음에 서재를 열 때 바로 나타납니다.
- KishinHisho_KO_20261118_HD : 4K 화면용 4배 그림(약 2.6GB)과 데몬베인 4배 텍스처.
  없어도 게임은 그대로 돌고, 2배·3배 창이나 모니터 전체에서 대사·전투 화면은 또렷하며
  CG·배경·메뉴 그림만 원래 그림을 부드럽게 키운 모습으로 보입니다.

■ 서재(LORE)에 책 더하기
- 서재 오른쪽 위 「책 들여오기」로 EPUB 파일을 고르면(여러 개 가능) 게임 폴더의 ko-library\books 로 복사되어
  그 책의 표지·제목과 함께 바로 나타납니다. EPUB 파일을 ko-library\books 에 직접 넣어도 됩니다.
  (EPUB 안에 표지 그림과 제목이 들어 있어야 합니다.) 빼려면 ko-library\books 에서 그 파일을 지우면 됩니다.

■ 알아 두면 좋은 것
- 화면 크기: 환경설정 → 기본 탭 「화면 크기」(원래 크기 / 2배 창 / 3배 창 / 모니터 전체). 누르는 즉시 바뀝니다.
- 모든 콘텐츠 열기: 환경설정 → 기본 탭 맨 아래 칸. 감상실·DUEL·스토리 차트 등이 다 열립니다(이야기 뒷부분이 보일 수 있음).
  세이브와 진행 기록은 바꾸지 않으므로 끄면 원래대로 잠깁니다.
- 게임 창이 뒤에 있는 동안에는 키보드·마우스 입력을 받지 않습니다(자동 전투는 계속 싸웁니다).
  끄려면 autobattle\autobattle.ini 의 [autobattle] 아래에 isolate_input=0 을 넣습니다.
- 대화 기록 점프와 전투 카메라 안내는 게임 폴더의 「대화 기록 점프 안내.txt」「전투 카메라 안내.txt」에 있습니다.
- 바뀐 점은 「한국어패치 안내\변경사항.md」, 함께 쓴 구성요소와 라이선스는 「한국어패치 안내\THIRD_PARTY.md」에 있습니다.
