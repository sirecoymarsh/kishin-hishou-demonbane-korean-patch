# 2026-11-18 판에서 바뀐 것 (10월 30일 판 이후)

## 새 기능
- **서재(LORE)**: 감상실에서 책을 읽는 서재. 마술사·마도서 사전과 데우스 마키나 사전이 들어 있고, 소설 6권은 따로 받는 꾸러미로 더합니다.
- **DUEL 정보 창**: DUEL 선택 화면에서 마술사·기체 칸을 누르면 마술사 / 마도서 / 기체 자료 / 기술표 / 기술 유래 / 기술명 대사 / 커맨드 리스트를 봅니다. 기술명 대사는 누르면 음성이 나옵니다. 본편을 끝낸 세이브에서는 잠긴 칸이 열립니다.
- **FINISHERS 목록**, **프리 파이트 컨티뉴**, 레무리아 엔딩 뒤 **「다시 마지막 전투로」**.
- **대화 기록 점프**(대화 기록에서 그 대사 자리로 이동)와 **전투 카메라**(시점 바꾸기). 안내는 게임 폴더의 두 txt.
- **4K 화면**: 환경설정 → 기본 탭 「화면 크기」(원래 크기 / 2배 창 / 3배 창 / 모니터 전체), 누르는 즉시 바뀝니다. 대사와 전투는 그 해상도로 그리고, 고화질 꾸러미를 더하면 그림과 메뉴 글자도 4배 그림으로 나옵니다.
- 전투 전 「저장할까요?」에 예 → 다음 빈 칸에 바로 저장. 게임 창이 뒤에 있어도 소리가 납니다.
- 환경설정 전투 탭에 난이도 설명.
- **모든 콘텐츠 열기**: 환경설정 기본 탭의 체크 칸. 켜면 감상실의 CG·DUEL 기체·스토리 차트·극장·피니셔와 DUEL 정보 창의 잠긴 칸이 모두 열립니다. 세이브와 진행 기록은 바꾸지 않으므로 끄면 원래대로 잠깁니다.

## 고친 것
- 한글이 든 설치 경로에서 첫 전투 직전·시스템 정보에서 게임이 꺼지던 것.
- 게임 창이 뒤에 있을 때 다른 창에서 친 키가 전투에 들어가 일시정지·종료되던 것(이제 뒤에 있는 동안 입력을 받지 않습니다).
- 확인 창이 영어·일본어로 나오던 것: T 키 「타이틀 화면으로 돌아갈까요?」, 창을 닫을 때 「게임을 끝낼까요?」(전투 중에도), 「영상을 건너뛸까요?」 등.
- DUEL 정보 창에서 대사를 재생할 때 아래에 빈 대화창이 잠깐 뜨던 것.
- 한국어 오프닝 두 편을 다시 만들어 찢김·늦게 도착하는 그림을 없앴습니다(800 판은 원래 800 그림에서).
- 패배하면 GAME OVER와 적 대사 뒤에 컨티뉴 창이 나오도록, 컨티뉴 단추는 원작 YES/NO 그림으로.
- 대사 줄 바꿈과 대사 창 줄 수(4줄), 로고 화면 한국어.

## DUEL·전투
- 균형 모드 AI 다수 손질: 로드 비야키·앰브로시우스·네로·크라켄·벨제부트 등 상대별 동작, 하드 모드 적 필살기 강화.
- 2P 크라켄·벨제부트·리베르 레기스·오거·네로의 잡기에서 붙잡힌 기체가 손에 붙지 않던 것.
- 웨이틀리 요그 소토스 주문 음성이 앞 음성에 막혀 안 나오던 것.
- 신수 형태는 원작 필살기 조건(체력 400 이하)으로.
- 이야기·프리 파이트의 어려움: 티베리우스 폭식 대죄·오거 비검·비룡·데몬 블러드 금기의 피 해방을 쓰는 동안 적이 받는 피해가 절반(끊기지 않음), 원령 주탄은 모으는 시간이 절반. 쉬움·보통은 그대로.
