# 구성요소와 출처

게임과 원래 자료의 권리는 원 저작권자(Nitroplus)에게 있습니다. 바꾸지 않은 원래 CG·음성·영상 자료는 싣지 않습니다.

## KHD Korean 글꼴
기존 작업판의 CP932 매핑용 수정 글꼴을 그대로 씁니다. 글꼴 메타데이터의 원저작권 표기는 © 2014–2021 Adobe이며, SIL Open Font License 1.1을 따릅니다. 수정 글꼴의 이름은 KHD Korean입니다.
- 원본 계열: https://github.com/notofonts/noto-cjk
- 라이선스: licenses/OFL.txt

## Locale Emulator (LoaderDll.dll, LocaleEmulator.dll)
일본어 코드 페이지로 게임을 돌리는 데 씁니다. 수정하지 않은 파일을 그대로 싣습니다.
- 원본 프로젝트·소스: https://github.com/xupefei/Locale-Emulator-Core
- 라이선스: GNU LGPL 3.0 (licenses/LGPL-3.0.txt, licenses/GPL-3.0.txt)

## FONTCHANGER.dll
기존 한국어화 작업에서 써 오던 글꼴 교체 도구를 수정하지 않고 그대로 씁니다(설정은 hook.ini).
